## Демонстрація програми
<img width="304" height="359" alt="image" src="https://github.com/user-attachments/assets/e819708b-a108-439a-8a3c-e3f17a97c5cc" />


Після виконання програми створюються два файли з результатами:
* **`output.txt`** - текстовий файл із таблицею значень функції, шифром групи та іменем студента
* **`data.bin`** - бінарний файл розміром **164 байти** (`4` байти на кількість точок `N = 10` + `160` байтів на 10 пар значень `double`). Після запису програма зчитує цей файл у динамічний масив і виводить таблицю (скриншот вище)
